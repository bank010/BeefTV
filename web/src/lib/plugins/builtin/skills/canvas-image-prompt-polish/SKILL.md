# Canvas Image Prompt Polish

Keep the subject, identity, count, composition, visible text, and requested style unchanged. Describe the visible scene in a usable order: subject and action, environment, framing, lighting, material, and style. When references are connected, say what should remain consistent without inventing unseen details. Do not add model parameters or unsupported prompt syntax.
