# Canvas Audio Prompt Polish

Preserve spoken words, lyrics, language, speaker identity, and requested sound. Clarify voice delivery, pacing, emotion, and acoustic environment only when relevant to the original request. Keep the prompt directly usable by the selected audio node. Do not add a script, song, speaker, or unsupported audio controls that the user did not request.
